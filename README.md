## 🔀 Our Git Workflow

To keep our project organized, we practice a simple Git workflow:

```text
main
 │
 ├── feature/nasya
 │
 ├── feature/jason
 │
 └── feature/keysia
```

Each member can work on their own branch before merging their changes into the main branch.

### Basic workflow

```bash
git clone <repository-url>

git checkout -b feature/your-name

git add .

git commit -m "Add new feature"

git push origin feature/your-name
```

After completing a feature, we can create a **Pull Request** and review the changes before merging them into `main`.
